## 店舗トップ `/{組織}`

並び: 上の帯 → 空いている公演を探す → 残りわずか → 友だちと貸切で遊ぶ → 作品から探す → はじめての方へ → フッター（アクセス）。

- 上の帯: 組織名、一言（組織設定 `public_booking_hero_description`、空なら自動「東京・埼玉 6 店舗のマーダーミステリー専門店」）、「はじめての方へ」（/guide）「店舗とアクセス」（フッターのアクセスへ）「貸切で遊ぶ」（貸切の区画へ）。背景は組織のテーマ色（無ければ #1f2a2e）、ヘッダー画像があれば暗く重ねる。
- 空いている公演を探す: 日付チップ（今週末／今日／明日／来週／日付を選ぶ＝月カレンダー。空きのある日に緑の点）、人数（1〜8 名、既定 2 名）、店舗（複数選択・何も選ばない＝すべて）、空席あり（既定オン）、初心者向け（作品タグ「初心者におすすめ」がある公演があるときだけ）。結果は公演を日付・時刻順、5 件ずつ「あと N 件を見る」。条件は URL（`?when=&date=&people=&stores=&avail=&beginner=`）に持ち、作品ページから戻っても同じ条件。
  - 今週末: 月〜土は直近の土日、日曜は次の土日（「今日」のチップがあるため。夜に開いて 0 件になるのを避ける）。
  - 出さない公演: 開始済み・予約締切（`reservation_deadline_hours`）を過ぎた公演、貸切・非公開・受付停止・店舗の公演募集停止期間。
  - 押すと作品ページを `?event=公演&count=人数` で開く（人数は残席まで）。作品ページはその公演を選び、人数を入れ、日程の位置まで送る（24 の解消）。
- 残りわずか: 残席 3 以下、または最低人数まであと 1〜2 人（成立間近）の公演を日付順に横スクロール。満席は出さない（23 の解消）。
- 友だちと貸切で遊ぶ: 「貸切できる作品を見る」（既存 `/{組織}/private-booking-select`）「貸切の流れ」（`/guide?section=private` で貸切予約ガイドへ送る）。
- 作品から探す: タグ（新作・人気・初心者向け・多いジャンル 3 つ・4/6/8 人）と 3 列（PC 6 列）のカード 12 件（次回の空きのある公演日順、無ければ「貸切で遊べます」）。「すべて（N）›」は既存の `/{組織}/catalog`（ジャンルのタグを選んでいれば `?genre=`）。
- 旧 3 タブ（ラインナップ／カレンダー／リスト）は廃止。`/{組織}/calendar`・`/{組織}/list` は `?when=date`（日付を選ぶ）へ、`/{組織}/private-booking` は貸切の区画へ送る。

## MMQ 全体トップ `/`

並び: 見出しと横断検索 → 「{日付}に入れる公演」 → 残りわずか（全店舗） → 友だちと貸切で遊ぶ → 作品から探す（全国） → 参加店舗 → はじめての方へ → 店舗の方へ。

- 見出し「全国のマーダーミステリー公演を、ここから予約」、「参加店舗 N ・ 公演 M 件（今後 2 週間）」。
- 横断検索: エリア（店舗の住所の都道府県）・日付・人数。結果は全組織の公演を日付順、「組織名 店舗名」付き。押すとその組織の作品ページを公演・人数を選んだ状態で開く。
- 残りわずか: 店舗トップと同じ部品（組織名を付ける）。
- 作品から探す: 全国の公開作品（作品マスタ単位）。補足「N 店舗で上演・次回 M/D」。「すべての作品（全国 N）›」は既存の `/scenario`、作品は既存の全国版作品ページ `/scenario/{slug}`。
- 参加店舗: エリアのチップ（検索のエリアと共通）、組織カード（ロゴ／頭文字、店舗名 4 つ「ほか N 店舗」、作品数、「今週末 N 公演に空きあり」）→ 店舗トップ。
- 店舗の方へ: 既存の問い合わせフォーム `/contact?type=partnership`（種別「MMQ への参加（店舗の方）」を選んだ状態）。
- 公開情報だけを読む: `schedule_events_public`・`stores_public`・`organization_scenarios_with_master`＋公開キー RPC・稼働中の組織（名前・slug・ロゴ）。公演は 1000 件ずつ最大 5 回読む（今日から 8 週間）。

## 数え方（1 つの計算元）

- 店舗数: `src/lib/publicStoreName.ts` の `countPublicStores`（臨時会場・休止中・オフィス〈名前に「オフィス」を含む店舗も〉を除く）。店舗トップの一言・全体トップの参加店舗数・組織カードで共通。
- 作品数: 店舗トップは予約サイトの作品一覧（公開キーで絞ったもの）＝`/{組織}/catalog` の件数。全体トップは稼働中の組織の公開作品を作品マスタで重複除き＝`/scenario` の件数（`/scenario` から休止中の組織の作品を外して揃えた）。
- 公演・残席・成立間近: `src/lib/publicPerformanceSearch.ts`。

## 店舗名（お客様向け）

`storeDisplayName`（`src/lib/publicStoreName.ts`）だけで決める。優先順:
1. 臨時会場は日付別の `temporary_venue_names`（無ければ `public_name`、それも無ければ「特設会場」）
2. 店舗設定の「お客様向けの名前」 `stores.public_name`（2026-10-11 追加。管理画面の店舗編集に入力欄）
3. 店舗名から組織名の接頭辞を外したもの（「クインズワルツ高田馬場店」→「高田馬場店」。外すと空なら元のまま）

使っている画面: 店舗トップ・全体トップ・フッターのアクセス・作品ページ（日程・会場アクセス・公演可能店舗・店舗の選択）・予約確認と予約確認メール（作品ページから渡る店舗名）・全国版作品ページ・貸切の作品選択／申込・グループページの作品情報の店舗一覧・マイページの予約カードと予約詳細。スタッフ向けの管理画面は従来どおり `name`／`short_name`。
未対応: グループページ・マイページの貸切カードで DB 関数（RPC）が返す店舗名、DB 関数・Edge Function が組み立てるメール（貸切の確定など）は従来の `name`。
