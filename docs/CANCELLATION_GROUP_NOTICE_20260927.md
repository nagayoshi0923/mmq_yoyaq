# グループ取消の整合性と通知の一括保存

案件 QW-20260917-001。全領域の整理は対応中。

## 変更

予約の本人・管理権限を確認後、貸切グループの組織と予約リンクを取消前に検証する。別組織・別予約・欠損はP0050/P0051で拒否し、APIは保存されていないことを409で案内する。グループと公演のロックはNOWAITとし、競合時は再試行を案内する。

グループ版も来場済み人数を集計し、中止済み公演の保存済み人数を保持する。取消前に公演をロックして人数再集計を行う。

新RPC `cancel_reservation_and_group_with_notice` が予約・グループ・組織設定から生成する通知を同一トランザクションで保存する。通知失敗時は予約・グループ・人数の変更も戻す。APIの通常取消・グループ取消経路を新RPCへ移し、APIからの生の通知保存を除去する。

## 確認

本番の未取消予約を読取集計: グループ欠損0、異組織参照5、同組織の別予約リンク0。不整合5件は所属を推測して変更しない。

隔離PGliteで実関数の組織・リンク不整合拒否、通知失敗時全体取消、真正本人・スタッフ・管理者、通知設定の組織分離、来場済み人数、中止済み人数保持、グループなし、匿名と本人偽装の拒否、重複取消拒否、復元再適用を確認した。API新規5件と既存7件、verify成功。NOWAITの並行セッション競合はこの隔離環境では未再現。

実予約取消・公演中止・通知送信は行っていない。DB適用・本番反映は未実施。
