## A. 共通 FAQ（設定 › FAQ の共通、14 件）

### A1. 予約はいつまでにすればいいですか？

- カテゴリ: 予約について
- 変更: 「前月10日ごろまで」を、画面と同じ「14日前まで」に

```text
▼オープン公演
募集している公演は、開始時刻まで予約できます。満席になると締め切りますので、お早めのご予約をおすすめします。
▼貸切公演
公演日の14日前まで受け付けています（店舗によって異なる場合があります）。休日は申し込みが多いため、お早めにお申し込みください。
```

### A2. 予約の変更はできますか？

- カテゴリ: 予約について
- 変更: 「日付」は変えられないので削除。変えられるのは人数とキャンセル。期限後は問い合わせフォームへ

```text
▼オープン公演
マイページの予約詳細から、人数の変更とキャンセルができます。日付の変更はできません。日付を変えたいときは、キャンセルしてから予約し直してください。
人数の変更は、予約詳細に表示される変更期限まで行えます。空き状況によっては、ご希望の人数に変更できない場合があります。
▼貸切公演
マイページの貸切カードの「操作」から、キャンセルができます。
▼期限を過ぎたとき
マイページの予約詳細にある「店舗に問い合わせる」からご連絡ください（予約番号が入った状態で送れます）。
```

### A3. 何人から予約できますか？

- カテゴリ: 予約について
- 変更: 変更なし

```text
オープン公演は1名様からご予約いただけます。シナリオによって最少催行人数が設定されている場合がありますので、各シナリオの詳細をご確認ください。
```

### A4. 友達と一緒に参加したい場合はどうすればいいですか？

- カテゴリ: 予約について
- 変更: 貸切の招待（登録なしで参加できる）を追加

```text
▼オープン公演
予約のときに参加人数を選んでいただくか、それぞれ別に同じ公演をご予約ください。
▼貸切公演
貸切のグループを作って招待リンクを送ると、お友達も参加できます。お友達はMMQに登録していなくても参加できます。
```

### A5. キャンセル料はかかりますか？

- カテゴリ: キャンセルについて
- 変更: 率の数字を書かない（店舗ごとに違うため）。※この質問は画面側でも「店舗のキャンセルポリシーをご確認ください」の案内文に置き換わる

```text
無料でキャンセルできる期限までは、キャンセル料はかかりません。期限を過ぎるとキャンセル料がかかります。
期限と料金は店舗ごとに決まっています。予約先の店舗のキャンセルポリシーでご確認ください。予約の確認メールとマイページの予約詳細にも、その予約の期限を表示しています。
```

### A6. キャンセル方法を教えてください

- カテゴリ: キャンセルについて
- 変更: 「キャンセル料金がかかる際は表示がございます」は実際と違う（ボタンが押せなくなる）ので直す。期限後は問い合わせフォームへ

```text
マイページの予約詳細を開き、「キャンセル」を押してください。
無料でキャンセルできる期限を過ぎると、マイページからはキャンセルできません（ボタンが押せなくなります）。その場合は、予約詳細の「店舗に問い合わせる」からご連絡ください（予約番号が入った状態で送れます）。
```

```text
受付で予約メールを確認しますので、スマートフォンをご用意ください。
```

### A9. 何分前に到着すればいいですか？

- カテゴリ: 参加について

```text
開始時刻の10分前にお越しください。10分前より早い開場はなく、待機スペースもありません。
初めての方は受付の手続きがありますので、遅れないようにご来店ください。
```

### A10. 途中参加・途中退出はできますか？

- カテゴリ: 参加について
- 変更: 変更なし

```text
マーダーミステリーは参加者全員で物語を進めるため、途中参加・途中退出はできません。公演時間を確認の上、最後まで参加できる日程でご予約ください。
```

### A11. 貸切とは何ですか？

- カテゴリ: 貸切について
- 変更: ガイドへの案内を追加

```text
主催者の方に参加者を集めていただき、店舗とスタッフを確保して、ご希望の日程で開催する仕組みです。
お友達やグループだけで遊べるので、参加者をご自身で集めたい方におすすめです。申し込みの流れは、使い方ガイドの「貸切予約ガイド」をご覧ください。
```

### A12. 貸切の料金はどうなりますか？

- カテゴリ: 貸切について
- 変更: 全角数字「１」を半角に

```text
貸切の場合、シナリオの最大人数分の参加料金です。シナリオカタログには1名様分の料金を表示しています。
```

### A13. 事前配役アンケートとは何ですか？

- カテゴリ: 貸切について
- 変更: 新しく追加（画面の名前「事前配役アンケート」にそろえる）

```text
作品によっては、貸切の日程が決まったあとに、やりたい役の希望などを伺う「事前配役アンケート」をお願いしています。グループページか、マイページの貸切カードから回答できます。
回答は店舗とGMだけが見ます（ほかのメンバーには見えません）。
```

## B. クインズワルツ個別 FAQ（設定 › FAQ の組織、7 件）

### B1. 支払い方法について

- カテゴリ: （なし）
- 変更: 変更なし

```text
現金やクレジットカード、交通系IC、iD、QUICPay、QRコード等のキャッシュレス決済が利用可能です。
```

### B2. 開演時間に間に合わない場合はどうしたらいいですか？

- カテゴリ: （なし）
- 変更: 誤字「問い合わせにてにご連絡」→「問い合わせにてご連絡」

```text
遅刻は厳禁です。
開始時間までにはご着席ください。
万が一遅れる恐れがある場合、直ちに問い合わせにてご連絡ください。
また、お客様都合でのキャンセルによる公演不成立は、公演料金全額を負担していただくことになりますのでご注意ください。
```

### B3. 着替えする場所はありますか？

- カテゴリ: （なし）
- 変更: 変更なし

```text
全店舗お手洗いは１箇所のみとなり、更衣室はございません。お着替えが必要な場合には公演開始１０分前にお越しいただき、開演までにご着席ください。
時間のかかる衣装は事前に着用をお願い致します。
```

### B4. 台風や災害時の公演はどうなりますか？

- カテゴリ: （なし）
- 変更: 変更なし

```text
台風等災害での公演の成否は、公共交通機関の計画運休に合わせて判断を行います。
前日に計画運休が首都圏で発令された場合、公演中止のご連絡をいたします。
その際はキャンセル料金は発生しませんのでご安心ください。
```

### B5. オープン公演の中止連絡・開催判断はいつ頃になりますか？

- カテゴリ: （なし）
- 変更: 「前日23:30〜24:00頃」を、キャンセルポリシーと同じ「公演開始の4時間前」に（社長決定 2026-10-12）

```text
開催・中止の判断は、公演開始の4時間前に行います。中止の場合はメールでお知らせします（参加料金はかかりません）。
最低開催人数にあと少しで届く場合は、公演開始の1時間30分前まで追加で募集し、そこで最終的に判断することがあります。
なお、満席の公演は開催が決まっているため、自動送信のリマインドメールだけをお送りします。
```

### B6. 問い合わせの返信はいつもらえますか？

- カテゴリ: （なし）
- 変更: 変更なし

```text
問い合わせの返信の窓口は、平日の10:00~17:00で対応しております。
先着より順番に対応するため、少々お時間がかかる場合もございますが2営業日以内に原則返信いたします。
土日祝で頂いたご連絡への返信には少々お時間を頂戴しますが、お待ちいただけますと幸いです。
```
