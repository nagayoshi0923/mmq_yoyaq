# QW-20260909-011：PR431の分離・店舗設定の保存修正

## 今回の変更

営業時間設定の「特別営業日」「特別休業日」は編集欄が存在する一方、読込時に空配列へ初期化され、保存対象にも含まれていなかった。両項目と備考を読み書きし、特別休業日は既存の予約判定が使う `holidays` と一致させる。旧 `holidays` だけにある日付は初回読込時に取り込み、削除後に復活しないよう保存する。

曜日・時間帯の既定値と正規化を `storeBusinessHours.ts` へ分離。曜日間・フォーム間で配列や開始時刻オブジェクトを共有しない。既存の休業指定、空の受付枠、保存済み開始時刻を維持する。

既存の店舗API（GET/PATCH action=businessHours）で、ログイン済みの組織IDと対象店舗の所属を検証する。保存は管理者に限定し、入力の組織ID・店舗ID・行IDを採用しない。読込と更新は組織ID・店舗IDで絞る。読込失敗時は保存を停止し、店舗切替前の応答を採用しない。更新エラーを新規作成に切り替えない。DBスキーマの追加・本番の設定変更・通知送信は含まない。
