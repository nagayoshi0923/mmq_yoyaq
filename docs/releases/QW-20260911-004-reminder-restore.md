# 貸切・オープンのリマインド分離

既存reminder_templateをオープン用として保持し、private_reminder_templateを貸切用に追加。予約・公演の保存情報で種別を判定し、顧客や呼出元から渡される文面を貸切用へ流用しない。貸切は店舗→組織既定→貸切専用既定文面の順で取得し、別店舗の独自文面やオープン用へフォールバックしない。

旧貸切専用本文は検索したGit履歴・email_settings監査履歴では確認できなかった。保存中の混在本文を基に、共通の来店案内を保持し、貸切からオープンの開催判断・48/24時間キャンセル料金・不成立時負担案内を除いた。貸切料金設定は現行7日前50%/3日前100%だが、予約時スナップショットとの差を避け、本文では予約時案内の確認へ誘導する。オープンから貸切30日前の操作期限だけを除く。既存本文のハッシュを照合し、変化していればmigrationを停止する。

設定画面の「予約関連メール」にオープン、「貸切予約関連メール」に貸切を表示。独立保存・読込・リセットを追加。スケジュールは従来どおり共通、送信時刻や開催判断ルールは変更しない。

## ロールバック

新しい列を残しても既存コードと互換。旧コード・対象Edgeへ戻す場合は文面混在が再発しないように注意する。保存文面の変更はmigration内の確認時ハッシュとレビュー資料を根拠に復元する。顧客・スタッフへテスト送信しない。
