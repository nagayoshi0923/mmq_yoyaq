# QW-20260907-005: シナリオ追加募集設定・部分辞退

## 今回の変更
- シナリオ編集「ゲーム設定」に、追加募集の有効/無効、不足人数（初期2名）、判断期限（初期90分前）を配置。
- 未案内の既存公演にも新設定を適用。案内済みの期限・不足人数基準は公演に保持。
- 公演詳細はシナリオ設定・変更履歴の参照のみ。追加募集の公演別上書きを廃止。既存の予約受付締切の公演別指定は別機能として維持。
- 「メール」に実送信と同じ本文生成関数を用いたサンプルを表示。
- 3名中1名など人数単位の無料辞退。残り人数・金額・履歴・辞退メールを更新。リクエストIDで再送を冪等化し、人数競合・将来の支払済み予約を拒否。
- 追加募集中の人数減少が設定を超えたら、同一トランザクションで運営Discordへ通知を予約。案内済み期限は維持。
- X投稿の待ち行列・承認済みアカウント検証・元投稿への結果返信・失敗/復旧通知を実装。通信結果不明なら再投稿せず運営照合を依頼。

## Xの有効化は接続待ち
本番Supabaseの設定名一覧に TWITTER_API_KEY / TWITTER_API_SECRET / TWITTER_ACCESS_TOKEN / TWITTER_ACCESS_TOKEN_SECRET は存在しない。`x_enabled` は初期false。接続設定と @queens_waltz の確認後、対象組織だけ有効にする。既存の別組織やステージから実投稿しない。過去の追加募集を遡って投稿しない。
